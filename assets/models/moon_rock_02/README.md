# Rock model

CC0 photoscanned boulder from [Poly Haven](https://polyhaven.com/a/moon_rock_02)
(`moon_rock_02`), re-exported at 512px / JPEG quality 72 for its three
PBR maps (from the 1k originals) to keep the fetch payload small -- see
#123 and ADR-0016. ~3.3k triangles, used instanced across all 64 rock
pile positions, desktop only (mobile keeps the procedural icosahedron,
see js/app.js).

CC0 -- no attribution required, credited here anyway as a courtesy and
so the source is traceable if the maps ever need re-exporting at a
different size.
