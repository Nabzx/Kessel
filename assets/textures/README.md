# Textures

CC0 PBR texture sets from [Poly Haven](https://polyhaven.com), re-exported
at 512px / JPEG quality 72 (from their 1k originals) to keep the fetch
payload small and predictable -- see #122 and ADR-0016.

| File prefix | Poly Haven asset | Used for |
|---|---|---|
| `rock_wall_09` | [Rock Wall 09](https://polyhaven.com/a/rock_wall_09) | Tunnel shell |
| `brown_mud_dry` | [Brown Mud Dry](https://polyhaven.com/a/brown_mud_dry) | Floor |
| `aerial_rocks_02` | [Aerial Rocks 02](https://polyhaven.com/a/aerial_rocks_02) | Rock pile |

CC0 -- no attribution required, credited here anyway as a courtesy and
so the source is traceable if the maps ever need re-exporting at a
different size.
