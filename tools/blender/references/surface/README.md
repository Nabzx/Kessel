# Surface film references

All third-party references here are CC0. They are retained for reproducible
local authoring, not fetched from a service by the demo. The Blender scene packs
its image dependencies. Source geometry and materials are illustrative, not a
survey or manufacturer digital twin.

- `corrugated-*.jpg`: [Corrugated Iron](https://polyhaven.com/a/corrugated_iron),
  photography by Dimitrios Savva, processing by Jenelle van Heerden. 1k diffuse,
  OpenGL normal and roughness maps. Physical repeat 1.1 m.
- `concrete-*.jpg`: [Concrete Wall 001](https://polyhaven.com/a/concrete_wall_001),
  photography by Dimitrios Savva, processing by Rico Cilliers. 1k diffuse, OpenGL
  normal and roughness maps. Physical repeat 1.5 m.
- `makehuman-base.obj`: [MakeHuman core base mesh](https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/3dobjs/base.obj),
  CC0 declaration retained in the file header. See the [core asset licence](https://www.makehumancommunity.org/about/license.html).
  The film derivative removes helper geometry, adjusts the arms, assigns full
  workwear and adds original PPE. MakeHuman source code is not included or used
  by the site.

The existing ground and rock scans retain their original manifests in
`assets/materials/` and `assets/textures/`. The representative sky is
[Kloofendal 48d Partly Cloudy Pure Sky](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky),
Greg Zaal and Jarod Guest, CC0. Its original download hash is recorded in
`assets/materials/sky-manifest.json`. This is not a Rwanda sky observation.
