# ADR-0064: Narrow receiver-frame qualification

Status: Accepted for the maintainer's repo-local continuation on 23 November 2026.
Extends ADR-0063's training-partition pilot. It does not rewrite ADR-0062 outcomes.

## Frozen method and cases

The pilot supports testing the already frozen receiver-x adapter with original
phase-memory weights for seeds 7/19/41. Do not fit, tune, add another method or
reselect weights after this protocol. The method uses conventional phase context
and an engineered input frame; every continuous action remains neural.

Reserve test bases 205800–205807 only after a full available-history/raw/ZIP audit
passes. A preliminary metadata check already rejected 206000 because older
world-model data used it; no new policy query was made on that proposal. Do not
call the replacement fresh merely because a text search finds nothing.

Evaluate nominal and the same 2 m farther receiver for each of the original and
adapted three seed policies, plus a separate conventional reference: 112 cases
on sixteen derived settings. Shared bases stay together. Both settings start
empty and retain the reference target of at least 2,000 kg delivered.

Each adapted seed must complete at least 7/8 in each family, with zero collisions.
Report all failures and paired baseline outcomes. No pooled average can override
a failing seed/family. This is narrow synthetic receiver-distance qualification,
not robustness to other piles, sensing failures or real machines.

## Work bounds

Audit is a serial local process with one CPU thread and a 180-second cap. Scan
all available Git/local raw data and retained ZIP members, including .local
candidate/pilot archives. Keep all outputs under the repository. An audit timeout,
unreadable archive or consumed hit blocks qualification; do not silently change
the range or expand its budget.

Qualification uses one CPU thread, no GPU, a 420-second execution cap and at most
67,200 evaluation decisions (112 × 600). Independently replay every adapted
physical trace, at most 28,800 additional decisions. Verify all learned actions
against recorded observations and original checkpoint identities separately.
Guard learned executions against reference-controller calls. Count separate
reference queries and all replay costs. Archive output is capped at 32 MiB.

If a cap is reached, retain partial data and mark admission false/incomplete.
Never expand the budget after observing failures. No optimiser updates or teacher
training labels. The eight bases are consumed once evaluation opens.

## Presentation boundary

Record new method identity, exact source hashes, checkpoint identity, nominal/
farther outcome and physical/action replay results. Preserve the earlier negative
stress catalogue and all old source capsules. No field, model-assisted-learning
or fully learned-planning claim is authorised. Integration into an existing
controller interface must retain the frozen original sources and disclose the
adapter explicitly. No visible browser or desktop automation, remote publishing
or machine connection is part of this work.
