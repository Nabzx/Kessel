# ADR-0086: Qualified harvest live integration

Status: Accepted for the maintainer's 28 November request to integrate the newly
qualified stack and merge the work. Earlier runtimes, numerical source, weights,
qualification capsules and visual review decisions remain unchanged.

Add a separate loopback-only harvest runtime and isolated viewer. Validate the
fresh qualification, accepted refusal record, frozen numerical libraries,
controller/model weights and source inventories before admitting a run. Practice
seeds remain 19000–19999. Primary delivery cases require the existing privileged
synthetic initial certificate: >=3200 kg above the blade and >=200 N empty forward
margin. Refuse unsupported requests before any policy/physics query, without
replacing the active run. The explicitly prepared no-progress fixture is admitted
only under its separate accepted/qualified empty-start hold scope.

Execute current observations, the frozen learned linear actuator with conventional
planning/guards and new physics on demand. Predict the next state before each
applied action, then retain its actual next-state error. The hybrid uses privileged
simulator state and known priors; label that boundary in the viewer/export. It
remains a shadow forecast with no influence on actions. The old world model and
older viewers do not inherit the new qualification or disappear.

Use request-driven play/pause/step/export with stale run/counter/epoch rejection,
atomic reset, independent logs and no background simulation clock. Bound batches
to ten decisions and runs to the existing 600-decision task or ten-second hold.
Keep source labels, accepted holds and deliveries distinct. Export complete sensor,
command, forecast and physical records. Importing modules binds no socket; the
CLI binds a new optional loopback port only when deliberately started. Do not
start it during this work or interfere with existing services/browser tabs.

The isolated viewer retains the existing Space/Jet, black/off-white and restrained
amber direction. A large scene and a narrow inspection panel show the loader and
one-step forecast together; detailed source hashes live in disclosure. Keep visible
focus and reduced motion. Test DOM-free presentation/client logic with Node and
backend sessions/HTTP handlers in-process. No browser automation, screenshots,
visual acceptance, release tag or public deployment is implied.
