# Reference assets

These files support the isolated Phase 11 visual prototype. They are not
loaded by the main cinematic page. Hashes, source URLs, byte sizes, roles,
physical scale and processing are recorded in `../manifest.json`.

Rock Face 03: Dario Barresi (photography), Rico Cilliers (processing),
[Poly Haven](https://polyhaven.com/a/rock_face_03), CC0 1.0.
Dark Rock 02: Amal Kumar,
[Poly Haven](https://polyhaven.com/a/dark_rock_02), CC0 1.0.
The eight 1K JPEG maps are official unmodified downloads; source MD5 values
were checked and local SHA-256 hashes recorded. Base colour is sRGB; normal,
roughness and occlusion data are linear. Normal maps use OpenGL orientation.

`slovenia-tunnel.bin` and its JSON metadata derive from *UWB Measurements and
3D Model of a Mine Tunnel*, v1.0, by Andrej Hrovat, Aleš Simončič, Grega Morano,
Teodora Kocevska and Tomaž Javornik, Jožef Stefan Institute.
[Source](https://zenodo.org/records/18835599),
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Changes: a longitudinal crop, centring and rotation for viewing. Units and CRS
remain unknown. It is not Rutongo geometry or a calibrated collision mesh.

The existing excavator, floor and ore maps are reused from their original
paths with their retained notices. No new machinery or NASA model is imported.
The official Rock 030 download returned HTTP 403. Its metadata was readable,
but it is not included. Dark Rock 02 is the available comparison alternative.
