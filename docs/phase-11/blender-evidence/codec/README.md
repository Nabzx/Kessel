# Local texture study dependencies

Pinned Three.js r160 example modules, copied without modification from
https://github.com/mrdoob/three.js/tree/r160/examples/jsm:
KTX2Loader, WorkerPool, ktx-parse, zstddec and Basis Universal transcoder.
Three.js is MIT licensed; the retained copyright notices in these modules
apply. Basis Universal is copyright Binomial LLC, Apache 2.0. This directory
supports an offline research comparison and is excluded from static packaging.
The production website does not load these decoders.
