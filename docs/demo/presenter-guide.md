# Presenting the Phase 9 demo

Start the local server from the repository root with
`python3 -m http.server 8080 --bind 127.0.0.1`. Open localhost:8080 in a
browser with hardware acceleration enabled. The Google satellite stage
requires internet; `?offline=1` keeps the complete mission local.

## A short walkthrough

**Earth, about 10 seconds.**
“Kessel is physical AI for extreme environments. Underground machines cannot
rely on GPS or a cloud connection. We train the policy in a world model and
run it on the machine.” Select Underground. Space, deep sea and glaciers
show the intended expansion without suggesting that those demos are ready.

**Rutongo, about 10 seconds.**
“This is the Rutongo area in Rwanda. The surface context is public. The
underground network you are about to see is an illustrative scenario.”
Use the satellite view, then enter the mine. The local site model is
available through the adjacent switch.

**Fleet, about 15 seconds.**
“Three trucks share a decline. Independent routes create waiting time.
The training process can evaluate coordination in simulation.” Run the
preview. “These figures and the 100,000-run trace are scripted to explain
the product; this browser is not running a trained policy.”

**Truck, about 20 seconds.**
Select HT-01 and Watch a complete haul cycle. Show the excavator loading the
truck and move the prediction horizon. “The policy is compressed onto rugged
compute and retrofitted to an existing machine. Sensors and control stay local,
so work continues without a connection. Deployment data improves the world
model when a connection returns.”

The complete cycle is time-compressed and may run beyond this short pitch.
Escape returns to the fleet without resetting the result. Mission select
restarts from Earth.

## Product context

The first commercial product targets loaders. The truck fleet is a visual
scenario for explaining the broader approach. Revenue is a retrofit kit plus
a per-machine software licence. This demo does not establish vehicle safety,
policy performance or deployment readiness.
