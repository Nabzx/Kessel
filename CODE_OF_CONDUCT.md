# Code of conduct

Kessel is a private repository with one maintainer, so this is short.

In issues, pull requests, and any other space tied to this project: be civil,
stay on topic, and assume good faith. No harassment, no personal attacks, no
spam.

The maintainer moderates these spaces and may edit, lock, or delete anything
that breaks the above.

Report a problem to nabilshahx@gmail.com.
